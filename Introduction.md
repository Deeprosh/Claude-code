# What is Claude Code?
Claude code is an AI agent that is developed by the company called "Anthropic".  

### Difference between an AI assistant and AI agent?  
* On daily basis, you will go to chatgpt which is an AI assistant and you can ask a question and it will answer.For example, if you a to-do list task/project it will tell you to do some steps which literally needs human intervention.  
* An AI agent will execute end to end tasks when you give a to-do list task without human intervention by giving the url as final result.
